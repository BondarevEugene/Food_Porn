# Little Legend — два разных PDF-артефакта

## Редакторский proof

Внутренний предпросмотр сохраняет пометки `EDITORIAL PROOF`,
«РЕДАКЦИОННЫЙ МАКЕТ» и редакционное заключение.
Его нельзя продавать как типографически готовое издание.

## Финальная цифровая книга

После подтверждённой оплаты paid worker вызывает
`assemble_stored_book_proof(..., edition="digital")`.
Это сохраняет проверки родительского утверждения всех глав,
совпадения ревизий иллюстраций, S3 и структурного PDF preflight,
но исключает редакционные водяные знаки и техническую последнюю страницу.

Обложка, посвящение, главы и утверждённые иллюстрации остаются.
Доступ к готовому PDF остаётся ограничен владельцем и подтверждённой оплатой.

## Границы

- Цифровой PDF **не равен** печатному тиражу. Цветовые профили,
  вылеты, переплёт и типографская подготовка не сертифицированы.
- Уже отправленные и сохранённые PDF не изменяются автоматически.
  Для старых заказов нужна отдельная контролируемая регенерация
  после сверки оплаты и доставки.
- Проверка визуальной композиции на реальных длинных рукописях
  обязательна перед коммерческим запуском.

## Приёмка

```powershell
python -m ruff check app src tests alembic main.py
python -m pytest -q tests/test_little_legend_illustrated_pdf.py tests/test_little_legend_digital_edition.py tests/test_little_legend_stored_book_proof.py
```

Сравнить редакционный proof и оплаченный digital PDF: отсутствие
редакторских надписей, корректность кириллицы, полные главы,
обложка и изображения без обрезки лиц.
