# Little Legend — контроль качества оплаченной цифровой книги

## Что изменилось

Перед загрузкой PDF в приватный S3 оплаченный worker проходит
дополнительный **offline quality gate**. Он отклоняет:

- повреждённый или слишком большой PDF;
- неверный формат страниц, недостаточное число страниц;
- редакционный proof, технические пометки и черновые подписи;
- пустую обложку или посвящение;
- отсутствие утверждённой иллюстрации на обложке;
- неполный набор заголовков глав.

Проверка работает **до S3 put и Telegram send**, не требует сети,
не вызывает платный AI и не передаёт клиентский текст в логи.
Редакторский proof остаётся доступен для предварительной проверки,
но не может быть выдан вместо оплаченной книги.

## Приёмка

```powershell
python -m ruff check app src tests alembic main.py
python -m pytest -q tests/test_little_legend_digital_delivery_gate.py
python -m pytest -q
```

Проверить: короткую и длинную сказку, несколько сцен, русскую/украинскую
кириллицу, размер PDF и обложку. Если gate отклоняет заказ,
оператор должен увидеть ошибку в Little Legend Mini CRM.

## Важно

Структурный gate не гарантирует художественное качество, отсутствие
визуальных коллизий или готовность к типографской печати.
Для этого нужны отдельные визуальные и полиграфические проверки.
