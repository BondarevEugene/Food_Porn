# Little Legend — оформление цифровой книги

## Три палитры

- **lavender** — лавандовая, светло-сиреневая и небесная.
- **ocean** — морская, прохладная бирюзовая и голубая.
- **sunrise** — тёплая кремовая, персиковая и терракотовая.

`render_illustrated_proof(..., edition="digital", palette="ocean")`
создаёт чистовую книгу с выбранной палитрой. Значение по умолчанию —
`lavender`; существующие заказы не меняют цвет без явного выбора.

Палитра оформляет бумагу, декоративные акценты, заголовки и колонтитулы.
Она **не изменяет** утверждённые фотографии и иллюстрации.
На страницах глав появляется отдельная строка номера и увеличенный
заголовок. Редакторский proof остаётся прежним по смыслу.

## Ограничения

Это улучшение цифровой A5-верстки, не печатный стандарт.
Параметр палитры доступен в программном API сборки; интерфейс выбора
покупателем и хранение его выбора в заказе в этот PR не входят.
Для печати нужны вылеты, CMYK и типографская приёмка.

## Приёмка

```powershell
python -m ruff check app src tests alembic main.py
python -m pytest -q tests/test_little_legend_premium_layout.py tests/test_little_legend_digital_delivery_gate.py
python -m pytest -q --tb=short -rs
```

Визуально проверить все три палитры на реальной книге, переносы
длинных заголовков, главы с несколькими страницами, кириллицу и
целостность иллюстраций.
