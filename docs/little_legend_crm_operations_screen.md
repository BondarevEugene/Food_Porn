# Little Legend — единый экран производства в Mini CRM

Раздел **Little Legend · производство** объединяет два существующих
источника данных в одной странице:

1. `/crm/api/little-legend/paid-production?limit=100` — оплаченные
   книги, состояния сборки, сохранённые PDF, диагностика зависаний.
2. `/crm/api/little-legend/delivery-queue` — журнал неопределённых
   Telegram-операций, диагностика и строго ограниченное восстановление
   подтверждённой проекции без повторной отправки.

## Приёмка

- Откройте `/crm` с ролью owner и выберите Little Legend.
- Проверьте пять счётчиков, таблицу оплаченных книг и журнал Telegram.
- Нажмите «Диагностика» для неопределённой доставки.
- Проверьте на телефоне горизонтальную прокрутку таблиц.
- Проверьте, что пользователь без роли owner не видит раздел и не
  получает данные по прямому API URL.
- Проверьте пустые очереди, ошибки сети, обновление и перезапуск Railway.

Страница не содержит детских фотографий, рукописей или PDF-байтов.
Операции повторной отправки нет: неопределённый результат Telegram
требует ручной сверки.

## Ограничения

Это интерфейс операционного наблюдения, не конструктор печатной книги.
Полный E2E реального платежа, S3 и Telegram должен быть отдельно
проверен в staging перед включением коммерческого трафика.
