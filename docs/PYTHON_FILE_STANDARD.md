# Стандарт заголовков Python-файлов

Каждый новый Python-файл проекта `Food_Porn` начинается с модульного docstring-заголовка. Заголовок является частью документации и должен обновляться вместе с обязанностями модуля.

```python
"""
==========================================================
FOOD_PORN

Module: Human-readable module name
Layer: Application layer

Responsibilities:
    - First responsibility
    - Second responsibility
    - Third responsibility
==========================================================
"""
```

## Обязательные правила

1. `Module` кратко объясняет назначение файла, а не повторяет его путь.
2. `Layer` указывает архитектурный слой: Entry Point, Telegram Interface, Domain, Persistence, Service, Rendering, Worker, Migration, Script или Test.
3. В `Responsibilities` перечисляются только реальные обязанности текущего файла.
4. Заголовок должен оставаться первым выражением файла, чтобы Python распознавал его как модульный docstring.
5. После заголовка располагаются `from __future__` и остальные импорты.
6. Секреты, токены, пароли и реальные строки подключения в заголовках и комментариях запрещены.
7. Декоративные разделители внутри больших файлов допустимы только между смысловыми разделами и не должны заменять функции, классы и нормальную архитектуру.

Этот стандарт основан на оформлении `NUMEROLOGY_SYSTEM/engine/legacy_engine.py` и обязателен для всех последующих Python-модулей проекта.
